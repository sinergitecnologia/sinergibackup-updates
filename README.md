# Sinergi Backup Updates

Repositório público de metadados de atualização do Sinergi Backup.

## Canais

- `channels/stable.json` — versões estáveis para clientes.
- `channels/beta.json` — versões de teste.

Os instaladores e pacotes devem ser publicados preferencialmente em GitHub Releases. Os manifestos apontam para a versão, URL do pacote, hash SHA-256 e notas de versão.
